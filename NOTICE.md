# Project conventions and sources

This independent provider follows architecture, contributor and release conventions
from these MPL-2.0 projects by the same maintainer:

- https://github.com/Scriptception/terraform-provider-misp
- https://github.com/Scriptception/terraform-provider-airlock
- https://github.com/Scriptception/terraform-provider-mimecast

The complete MPL-2.0 license text is retained in LICENSE. The release workflow and
GoReleaser configuration were adapted from the Mimecast reference checkout.
Implementation and synthetic fixtures were written for the public AlgoSec A32.60
contracts linked in docs/api-coverage.md. AlgoSec documentation is not relicensed
by this project; source HTML is not distributed here.
