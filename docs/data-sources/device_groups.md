# algosec_device_groups (Data Source)

EXPERIMENTAL ASMS A33.20 Early Availability API. Requires experimental_device_groups=true and complete administrator inventory visibility. AlgoSec does not recommend these APIs for production use. Reads the complete group inventory.

Targets only the [A33.20 EA inventory contract](https://techdocs.algosec.com/en/asms/a33.20/asms-help/content/api-guide/groups_list_dev_get.htm). The [vendor warning](https://techdocs.algosec.com/en/asms/a33.20/asms-help/content/api-guide/managing-devices-and-groups.htm) advises against production use. The experimental gate defaults to false; read_only remains true. Exact display-name lookup uses the complete validated inventory, never a detail-endpoint 404. Requires complete administrator visibility; filtered but structurally valid inventories cannot be detected. Tested only against a synthetic HTTPS fixture, not an appliance.

## Example Usage

```terraform
# EXPERIMENTAL ASMS A33.20 Early Availability; vendor does not recommend production use.
provider "algosec" {
  experimental_device_groups = true
  read_only                  = true
}

data "algosec_device_groups" "example" {}
```
